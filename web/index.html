Reading the record

Filtered vegetation detections from NASA FIRMS are counted inside the selected rectangle. Province presets approximate their boundaries. The map shows archived detections for the selected timeline month. The basemap is current imagery.

One comparable calendar

All sensors use fire cell-days: each 0.01-degree grid cell counts once per day (approximately 1 km, varying with latitude). MODIS is calibrated to VIIRS S-NPP using 1-degree local cells and calendar-month ratios, shrunk toward regional ratios for sparse cells. Terra-only reconstruction before Aqua uses the 2012-2019 calibration period. Sensor coverage determines which product is used. Raw MODIS and VIIRS values in the detail view remain pixel detections.

Historical normal

Each month is compared with the same calendar month in other complete years, excluding the year being assessed. Partial months and zero baselines have no percentage comparison. Reconstructed values include an area-specific monthly error band in the CSV.

Policy comparisons

The checker compares complete seasons against the selected area's median seasonal error from held-out years. This is a model error reference, not a statistical significance test. Timing shifts and observation coverage affect the evidence. A before-and-after comparison cannot establish what caused a change.
